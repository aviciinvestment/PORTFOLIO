RESOLVED - 2026-09-20 (the actual build blocker)
=================================================
`npm run build` on a fresh machine failed, which explains everything:

   src/app/api/admin/sync-rag/route.ts - Property 'resumeText' does not
   exist on type '{ ... resumeUrl: string | null; }' (Prisma SiteContent)

CAUSE: prisma/schema.prisma has the resumeText column, but the generated
Prisma client checked in node_modules was built BEFORE that column
= stale types. `npm run build` did not regenerate the client, so the
typecheck failed, the Vercel deploy failed, and Vercel kept serving the
ORIGINAL (old) site - the big resume button / Next icon you saw.

FIX (applied + verified locally):
  - package.json: "build" is now "prisma generate && next build" and a
    "postinstall": "prisma generate" hook was added, so every fresh
    install or build regenerates the client from the schema.
  - Ran `npx prisma generate` (succeeded, client regenerated).
  - `npx tsc --noEmit` passes; resumeText resolves.

DEPLOYMENT STATUS NOW: CAN DEPLOY. Push this package.json change, or run
`npm install`/`npm run build` locally, then deploy. The next successful
build will show the fixed nav, admin, and favicon.
